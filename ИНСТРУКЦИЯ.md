## 1. ЦЕЛЬ
Написать (или доработать) Python-программу, которая автоматизирует весь процесс создания статьи:
**структура → таблицы ДО → статья (≥20 мин чтения) → верификация → исправление → 5 заголовков → 5 обложек.**
Программа сама вызывает API Claude; проверки, которые ИИ делает плохо (счёт, повторы, длина), выполняет КОД.

## 3. СЛАБОСТИ ИИ В КОДЕ И КОМПЕНСАЦИЯ

| Слабость | Компенсация |
|----------|-------------|
| Выдуманные параметры API/библиотек | Сверять с ИСТОЧНИКИ.md §1; не уверен → пометка `# TODO: проверить по доке`, не угадывать |
| Lost in Middle | Читать ВСЕ файлы от начала до конца; не пропускать СТРУКТУРА.md §2–3 |
| Код «выглядит рабочим», но не запускался | Обязательный `--dry-run` и `--check-only`; тесты из Семейные_драмы.txt §4 |
| Путаница в именах/схемах | Схемы только из СТРУКТУРА.md §3, копировать, не изобретать |
| Хрупкий разбор JSON из ответа модели | Один `extract_json()` на всю программу; для длинных текстов — разделители `## ...`, не JSON |
| Усечение длинного вывода | Потоковый запрос (`stream`) + `max_tokens` с запасом; проверка длины после генерации |
| Ключи в коде | Только `os.environ["ANTHROPIC_API_KEY"]` |
| Молчаливые ошибки | Любая ошибка → `log()` + понятное сообщение; повтор до 4 раз с паузой |

## 4. ПРИНЦИПЫ
1. **Копирование.** Имена функций, ключи JSON, названия файлов — как в СТРУКТУРА.md. Не переименовывать.
2. **Код считает, ИИ понимает.** Всё измеримое (слова, %, повторы, даты, длина заголовка) — Python. Смысл (факты, цитаты, тон) — модель.
3. **Тесты до сдачи.** Нет прогона `--dry-run` и `--check-only` → код не готов.
4. **Явность.** Пороги — константы в начале файла (СТИЛЬ.md §3), не «магические числа» в теле функций.
5. **Одна задача — один файл-результат.** Сначала план модулей (3–6 строк), потом код.

## 5. ПРОЦЕСС

**Этап 1. Чтение.** Прочитать все 6 файлов целиком. Выписать: какие проверки обязательны (СТРУКТУРА.md §4), какие пороги (СТИЛЬ.md §3).
**Этап 2. План.** Кратко: модули, поток данных, что делает код / что делает ИИ.
**Этап 3. Код.** По модулям из СТРУКТУРА.md §1. Стиль — СТИЛЬ.md §1–2. API — по ИСТОЧНИКИ.md.
**Этап 4. Самопроверка.** Прогнать примеры из Семейные_драмы.txt §4; сверить ожидаемые статусы.
**Этап 5. Сдача.** Код + 3–5 строк запуска + список допущений и того, что НЕ проверено (например, реальный вызов API).

## 7. ПРАВИЛА СОДЕРЖАНИЯ (программа должна их проверять — детали в СТРУКТУРА.md §4)
- Объём ≥ 20 минут (по умолчанию 200 слов/мин → 4000 слов; настраивается).
- Нет клише (СТИЛЬ.md §4), нет морали в финале, нет повторов >2 раз.
- Монетизация Дзена: событие → реакция; без деталей травм/насилия/эротики; при теме насилия — триггер-предупреждение + 8-800-2000-122.
- Факты и цитаты — только из белого списка (ИСТОЧНИКИ.md §3); нет факта → метка `[ТРЕБУЕТ ИСТОЧНИКА: "..."]`.
- Актуальный год: 2026. История «из жизни» → «имена изменены».
