| Тип | Минимум источников |
|-----|--------------------|
| Статистика разводов/браков, юр. нормы, диагнозы, насилие, медицина стресса | 2 (Ур.1–2) |
| Динамические данные (пособия, прожиточный минимум) | свежесть: пособия <1 мес, ПМ <3 мес |
| Общий контекст | 1 (Ур.2–3) |

### Принцип «Я не знаю» (реализуют промты и проверка кода)
1. Нет факта в источниках → `[ТРЕБУЕТ ИСТОЧНИКА: "..."]`, число не придумывать.
2. Данные старше 3 лет (статистика) / 1 года (законы) → `[УСТАРЕВШИЕ ДАННЫЕ: ...]`.
3. Источники противоречат → показать оба, не выбирать удобный.
4. Никаких конкретных юридических/медицинских предписаний — «обратитесь к юристу/психологу».
5. Цитата реальному человеку без строки в таблице атрибуции — запрещена.

### Этика
Дети — без идентифицирующих деталей · насилие — триггер-предупреждение + 8-800-2000-122 · суицид — по рекомендациям ВОЗ https://www.who.int/ru/news-room/fact-sheets/detail/suicide · обвинения реальных людей без решения суда — запрещены · история «из жизни» → «имена изменены».
