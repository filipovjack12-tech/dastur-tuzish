---

## 1. СТИЛЬ КОДА
- Python 3.10+, один файл `dzen_pipeline.py` (пока < 800 строк), без лишних зависимостей (только `anthropic` + стандартная библиотека).
- Имена: функции `snake_case`, константы `UPPER_CASE`, шаги пайплайна — `step_<название>` (`step_structure`, `step_tables`, `step_write`, `step_fix`, `step_titles`, `step_covers`).
- Комментарии и сообщения пользователю — по-русски, коротко: «что и зачем», не «как».
- Типы в сигнатурах, функции ≤ 40 строк, одна функция — одна задача.
- Логи: `log("...")` с временем; ошибки API — повтор до 4 раз, пауза 5·N секунд.
- Файлы читать так: `utf-8-sig`, при ошибке `cp1251`. Писать всегда `utf-8`.
- Ключ: только `os.environ["ANTHROPIC_API_KEY"]`; в код, логи и результат не попадает.
- Выход программы: код возврата 0 — готово, 1 — остались ошибки верификации.

## 2. СТИЛЬ ПРОМТОВ (внутри программы)
- System-промт = все 4 md-файла целиком, с заголовками `===== ИМЯ =====`; помечать `cache_control: ephemeral`.
- Короткие ответы (структура, таблицы, обзор, заголовки) — «верни ТОЛЬКО JSON» с примером схемы.
- Длинные (статья, исправление) — обычный текст; если нужны две части — разделитель `## ИСПРАВЛЕННАЯ СТАТЬЯ`.
- В каждом промте: тема, номер шага, жёсткие требования (объём, таблицы для копирования), «без комментариев».
- Запрос длинной статьи — потоковый (`client.messages.stream`), `max_tokens` ≥ 32000.

## 4. СПИСКИ, КОТОРЫЕ ПРОГРАММА ХРАНИТ КОНСТАНТАМИ

**Клише (нижний регистр, подстрока):** сердце сжалось · слёзы ручьём / слезы ручьем · душа разрывалась · боль пронзила · мир рухнул · семья — это главное · только пройдя через боль · жизнь никогда не будет прежней · любовь всегда найдёт дорогу · берегите тех, кто рядом · в данной ситуации · следует отметить · на протяжении длительного времени · взаимоотношения между супругами · осознав всю серьёзность

**Мораль в финале (последние 3 строки):** берегите · помните · главное в жизни · семья — это · не забывайте · будьте счастливы

**Запрещённые темы (с границей слова `\b`):** изнасил · труп · кровь/кровью · кровав · самоубий · суицид · расчленен · пытк · порно

**Насилие (требует предупреждение + телефон):** избил · избива · ударил · бил · насили · побои · душил

**Слова-повторы по умолчанию:** предательство · больно · она поняла

**Метки «Я не знаю»:** `[ТРЕБУЕТ ИСТОЧНИКА: "..."]` · `[УСТАРЕВШИЕ ДАННЫЕ: ...]` — наличие любой в финале = ошибка.

## 5. ЛИТЕРАТУРНЫЕ ПРАВИЛА (для промтов, не для кода)
Тон тёплый разговорный с горечью · начало с конкретики · диалог без лишних ремарок · финал — деталь или реплика, без морали · романтика: слово + одно действие · медицина/травмы: событие → реакция · кульминация — самое короткое предложение.
